Preprocessing
=============

Explore phase retrieval followed by reconstruction of a biological sample,
and experimental-data stripe-removal comparisons.

.. toctree::
   :maxdepth: 1

   Paganin reconstruction of a biological sample <paganin_reconstruction>
   Five stripe-removal methods <stripe_removal>

The Paganin example uses I12 dataset 6 and reconstructs five central slices,
comparing results with and without phase retrieval. It uses structural and
finite-value checks.

Stripe comparisons cover sixteen parameter combinations; Raven uses
detector rows 10:20.
