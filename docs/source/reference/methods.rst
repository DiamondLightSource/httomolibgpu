.. _reference_methods:

Method guides
-------------

Browse every public processing method and utility by task. Each guide explains
the method, when to use it and its main controls, with equations and illustrations
where useful. Follow the API reference link on a guide for the exact signature
and parameter types; every function in :ref:`reference_api` links back to its guide.

For array layout, units and processing order, start with
:doc:`../introduction/workflow`.

Developer utilities are listed separately from tomography processing methods.
